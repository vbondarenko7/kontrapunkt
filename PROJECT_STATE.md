# salon-landing

## Статус

Сайт работает на `https://jazzgovorit.ru/` через GitHub Pages. Сертификат Let's Encrypt выпущен
для apex и `www`, обязательный HTTPS включён; `www` перенаправляется на основной домен.
Цена билета — `2 300 ₽`; обе кнопки ведут на фиксированную ссылку Prodamus. Prodamus подключён к НПД.

## Структура

- `Джаз вечер. /Карта проекта.md` — главный документ проекта.
- `Джаз вечер. /Лендинг версия C/app/page.tsx` — лендинг и CTA покупки.
- `Джаз вечер. /Лендинг версия C/app/payment-success/page.tsx` — успешная оплата.
- `Джаз вечер. /Лендинг версия C/app/payment-failed/page.tsx` — незавершённая оплата.
- `Джаз вечер. /Лендинг версия C/app/analytics.ts` — цели Яндекс Метрики.
- `Джаз вечер. /Лендинг версия C/tests/rendered-html.test.mjs` — проверки страницы.
- `CNAME` и `Джаз вечер. /Лендинг версия C/public/CNAME` — домен GitHub Pages.

## Ключевые решения

- Основной домен — `jazzgovorit.ru`; экранный бренд — «Разговор × Джаз».
- Для первой версии используется существующий аккаунт Prodamus и короткая платёжная ссылка.
- Технический поддомен старого проекта допустим и не требует платной замены.
- Сумма и состав билета в публичной ссылке зафиксированы.
- Prodamus подключён к НПД для автоматических чеков и корректировок при возврате.
- Покупатель и гость — разные роли; ядро первой продажи — женщина 28–42, планировщик вечера.

## Что сделано

- Timeweb DNS настроен на GitHub Pages; `www` и почтовые записи сохранены.
- Custom domain переустановлен через GitHub Pages API для перезапуска сертификата.
- Сертификат выпущен, HTTPS включён и проверен для `jazzgovorit.ru` и `www`.
- Prodamus переименован под новый проект, адрес сайта и возврат после оплаты настроены.
- Создан билет «Билет на вечер Разговор и Джаз» стоимостью `2 300 ₽`.
- CTA подключены к Prodamus; добавлена цель Метрики `ticket_click`.
- Добавлены и визуально проверены страницы результата оплаты.
- Подключение Prodamus к кабинету НПД подтверждено и проверено.
- Lint, 8 тестов и production build проходят.
