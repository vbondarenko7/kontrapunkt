# salon-landing

## Статус

Сайт работает на `https://jazzgovorit.ru/` через GitHub Pages. В исходниках готов выбор
от 1 до 6 билетов по `2 300 ₽`: сумма и обе кнопки покупки меняются вместе с количеством.
Для каждого варианта создана отдельная активная ссылка Prodamus. На продакшен новая версия
пока не опубликована.

## Структура

- `Джаз вечер. /Карта проекта.md` — главный документ проекта.
- `Джаз вечер. /Лендинг версия C/app/page.tsx` — лендинг и CTA покупки.
- `Джаз вечер. /Лендинг версия C/app/globals.css` — визуальная система и адаптивы.
- `Джаз вечер. /Лендинг версия C/public/host-vadim-portrait.webp` — портрет ведущего.
- `Джаз вечер. /Лендинг версия C/app/payment-success/page.tsx` — успешная оплата.
- `Джаз вечер. /Лендинг версия C/app/payment-failed/page.tsx` — незавершённая оплата.
- `Джаз вечер. /Лендинг версия C/app/analytics.ts` — цели Яндекс Метрики.
- `Джаз вечер. /Лендинг версия C/public/favicon.svg` и `favicon.svg` — актуальный знак сайта.
- Корневые HTML, TXT и `_next/` — статическая сборка GitHub Pages.

## Ключевые решения

- Основной домен — `jazzgovorit.ru`; экранный бренд — «Разговор × Джаз».
- Для оплаты используется существующий аккаунт Prodamus и короткие платёжные ссылки.
- Prodamus подключён к НПД для автоматических чеков и корректировок при возврате.
- Поле «номер заказа» в Prodamus необязательное, но скрыть его настройкой нельзя; внутренний
  уникальный ID платежа Prodamus создаёт сам.
- Платёжная ссылка Prodamus фиксирует количество. Для статического сайта используются отдельные
  неизменяемые ссылки на 1–6 билетов, а выбранное количество переключает ссылку на лендинге.
- Favicon — красная реплика со светлой джазовой нотой на почти чёрном фоне.
- Покупатель и гость — разные роли; ядро первой продажи — женщина 28–42, планировщик вечера.
- Портрет ведущего собран из двух личных референсов и приведён к клубной палитре сайта.

## Что сделано

- Timeweb DNS, HTTPS и редирект `www` настроены.
- Билет стоимостью `2 300 ₽`, цель Метрики `ticket_click` и страницы результата оплаты готовы.
- Портрет ведущего опубликован и адаптирован для desktop и mobile.
- В заголовке секции формата убрано тире.
- Точка таймлайна останавливается в центре нижнего кольца и не задевает текст.
- Мобильный акцентный заголовок больше не прижимается к краю.
- Созданы и проверены шесть активных ссылок Prodamus: от `2 300 ₽` за 1 билет до `13 800 ₽` за 6.
- В карточку билета добавлен нативный селектор количества 1–6, динамическая сумма и переключение
  обеих кнопок покупки на соответствующую ссылку Prodamus.
- Публичная платёжная форма и настройки Prodamus проверены: количество внутри фиксированной ссылки
  покупатель менять не может.
- Локально проходят lint, vinext build и 9 тестов; desktop, tablet и mobile проверены в браузере,
  горизонтального переполнения нет.

## Что дальше

1. После отдельной команды синхронизировать статическую сборку и опубликовать селектор на GitHub Pages.
2. Попросить поддержку Prodamus переименовать «номер заказа», чтобы убрать путаницу у покупателя.
3. Подтвердить дату, время, адрес, программу, оферту и условия возврата.
4. Провести контрольную оплату каждого количества и тестовый возврат с проверкой чеков НПД.
