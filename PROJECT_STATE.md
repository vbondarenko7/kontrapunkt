# salon-landing

## Статус
В работе. Актуальная версия доступна локально: `http://localhost:3000/`. GitHub Pages не обновлялся.

## Структура
- `Джаз вечер. /Лендинг версия C/` — актуальный лендинг.
- `Джаз вечер. /Лендинг версия C/app/page.tsx` — содержание и логика сцен.
- `Джаз вечер. /Лендинг версия C/app/globals.css` — визуальная система и анимации.
- `Джаз вечер. /Лендинг версия C/public/02-musical-response-1200.webp` — изображение трио, собранное в блоке музыкантов как единая трёхчастная сцена.
- `Джаз вечер. /Лендинг версия C/public/philosopher-scene.webp` — исходная сцена клуба.
- `Джаз вечер. /Лендинг версия C/public/candle-flame-cleanup.png` — локально скрывает исходный статичный язычок.
- `Джаз вечер. /Лендинг версия C/public/candle-flame-real.webp` — автоматически проигрываемая анимация настоящего пламени.

## Ключевые решения
- Первый экран не менять без отдельной просьбы.
- Вторая сцена механики называется «Музыка, которой раньше не было».
- После общей картины добавлен блок музыкантов, затем идёт тема первой встречи.
- Блок музыкантов объясняет не статус исполнителей, а их роль: они слушают беседу и отвечают ей импровизацией.
- Имена в составе пока обозначены заглушками; не выдумывать регалии и цифры до получения фактов.
- Маркер темы читается как «Тема первой встречи — № 01».
- Блок после темы: «Разговор без снобизма / Здесь не оценивают. Здесь слушают».
- Глаза статуи оставлены полностью исходными; не добавлять зрачки и моргание.
- Исходный язычок локально скрывается, затем на фитиль накладывается настоящая WebP-анимация через screen blending.
- GitHub Pages обновлять только по отдельной просьбе.

## Что сделано
- Добавлен полноценный блок «Музыканты вечера» между общей картиной и первой темой.
- Заголовок: «Они не сопровождают беседу. Они отвечают ей».
- Одна фотография трио собрана в три связанные части: рояль, контрабас и ударные.
- При входе блока в экран части сцены раскрываются последовательно; движение однократное и отключается при reduced motion.
- Добавлены адаптивная мобильная компоновка и временные места под имена.
- `npm run build`, ESLint и `git diff --check` проходят.
- Локальная страница и изображение возвращают `HTTP 200`.
- Старые starter-тесты ожидают уже удалённый preview skeleton и поэтому остаются неактуальными.
