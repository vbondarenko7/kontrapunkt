## Ключевые решения

- Основной домен — `jazzgovorit.ru`; бренд — «Разговор × Джаз».
- Группа — постоянная группа проекта; вечер 19 сентября создаётся внутри неё отдельным мероприятием.
- Название события — «Созданные друг для друга проходят мимо | Разговор × Джаз».
- Формулы «разговоры о главном» и «разговоры о важном» исключены.
- На сайте не показываются служебные заглушки и неподтверждённые ответы FAQ.
- В блоке формата закреплена фраза «За вечер этот цикл повторяется.» без количества циклов.
- Обычная цена билета — 2500 ₽; подписчикам нового канала вечера планируется цена 2250 ₽ по коду `2245`.
- Промокод процентный, чтобы скидка 10% корректно считалась при покупке 1–6 билетов.
- Долгие решения находятся в `DECISIONS.md`.
