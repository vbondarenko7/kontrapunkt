# salon-landing

## Статус

Сайт опубликован на `https://jazzgovorit.ru/` через GitHub Pages из `main`, коммит
`e78aea9`. На продакшене работает выбор от 1 до 6 билетов по `2 300 ₽`; сумма и
платёжная ссылка меняются вместе с количеством. Prodamus открывается в новой вкладке.
Файл подтверждения Яндекс Вебмастера опубликован и доступен.

## Структура

- `Джаз вечер. /Карта проекта.md` — главный документ проекта.
- `Джаз вечер. /Лендинг версия C/app/page.tsx` — лендинг, выбор количества и CTA покупки.
- `Джаз вечер. /Лендинг версия C/app/globals.css` — визуальная система и адаптивы.
- `Джаз вечер. /Лендинг версия C/app/payment-success/page.tsx` — успешная оплата.
- `Джаз вечер. /Лендинг версия C/app/payment-failed/page.tsx` — незавершённая оплата.
- `Джаз вечер. /Лендинг версия C/app/analytics.ts` — цели Яндекс Метрики.
- `yandex_6231a2b580647b9a.html` и его копия в `public/` — подтверждение прав в Яндекс Вебмастере.
- Корневые HTML, TXT, ассеты и `_next/` — статическая сборка GitHub Pages.

## Ключевые решения

- Основной домен — `jazzgovorit.ru`; экранный бренд — «Разговор × Джаз».
- Prodamus подключён к НПД для автоматических чеков и корректировок при возврате.
- Для 1–6 билетов используются шесть отдельных фиксированных ссылок Prodamus.
- Выбор количества расположен только в основной билетной карточке. Финальная кнопка прокручивает
  страницу к ней и не считается кликом покупки.
- Платёжная форма открывается в новой вкладке с `noopener noreferrer`.
- Поле «номер заказа» в Prodamus необязательно; переименовать его можно через поддержку.
- Файл подтверждения Яндекс Вебмастера не удалять после подтверждения прав.

## Что сделано

- Созданы и проверены шесть активных ссылок Prodamus: от `2 300 ₽` до `13 800 ₽`.
- Нативный список заменён на фирменный переключатель 1–6 с общей активной суммой.
- Обе кнопки называются «Купить билет»: основная открывает оплату, нижняя ведёт к карточке.
- Статический экспорт синхронизирован с корнем GitHub Pages без устаревших чанков.
- На живом домене проверено переключение с 1 на 6 билетов: `2 300 ₽` → `13 800 ₽`, ссылка
  меняется, ошибок браузера нет.
- Добавлен и опубликован `yandex_6231a2b580647b9a.html`; живой URL отвечает `200 OK`
  и отдаёт точный токен `6231a2b580647b9a`.
- Проходят lint, vinext build, Next.js static export и 9 тестов.

## Что дальше

1. В Яндекс Вебмастере нажать «Подтвердить».
2. Провести контрольную оплату каждого количества и тестовый возврат с проверкой чеков НПД.
3. Попросить поддержку Prodamus переименовать «номер заказа», чтобы убрать путаницу у покупателя.
4. Подтвердить дату, время, адрес, программу, оферту и условия возврата.
