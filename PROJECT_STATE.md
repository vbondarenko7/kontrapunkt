# salon-landing

## Статус
Версия D реализована и проверена в ветке `version-d`. `main` не изменён и сохраняет
версию C как точку отката. Публичная GitHub Pages-версия пока остаётся версией C:
`https://vbondarenko7.github.io/kontrapunkt/`.
Локальный сервер разработки доступен по адресу `http://localhost:3000/`, пока
активна текущая сессия.

## Структура
- `Джаз вечер. /Лендинг версия C/app/page.tsx` — девять секций, тексты и интерактив.
- `Джаз вечер. /Лендинг версия C/app/globals.css` — визуальная система и адаптив.
- `Джаз вечер. /Лендинг версия C/public/` — используемые изображения лендинга.
- `screenshots/version-d/` — контрольные кадры 1440×900 всех секций и ведущего.
- `Джаз вечер. /ЗАДАНИЕ — версия D.md` — утверждённое задание версии D.

## Ключевые решения
- Порядок версии D: hero → зачем идти → формат → тема → кто на сцене →
  здесь не оценивают → билет → FAQ → финал.
- Первый экран изменён только в факте «Когда».
- Тема первой встречи: «Созданные друг для друга проходят мимо».
- Музыканты и ведущий объединены в одном блоке; отсутствующие факты видимо помечены
  `[ЗАПОЛНИТЬ: …]`.
- Секция «Каждая встреча — картина» и старый визуал темы удалены вместе с ассетами.
- Коммерческий слой и техническая оптимизация не входят в версию D.

## Что сделано
- Все восемь задач версии D реализованы отдельными коммитами.
- На странице ровно девять секций в утверждённом порядке.
- Удалены старые `collective-*` и `tragic-*` код, эффекты и ассеты.
- Добавлены блоки «Зачем идти», новая CSS-композиция темы и подблок ведущего.
- Переписаны блок «Здесь не оценивают», FAQ и факт на первом экране.
- Устранены горизонтальные вылеты на 1024–1440 px, наложение hero на следующий
  экран и обрезка правой части блока темы.
- Исправлены финальная линия секции формата, мобильный перенос заголовка hero и
  интервалы между абзацами ведущего.
- `npm run lint` и `npm run build` проходят.
- Браузерная проверка выполнена на ширинах 390, 768, 1024, 1280 и 1440 px;
  дополнительно проверено окно покупки на мобильном и десктопе. Горизонтального
  переполнения и битых изображений нет.
