# salon-landing

## Статус
В работе. Актуальная версия опубликована на GitHub Pages: `https://vbondarenko7.github.io/kontrapunkt/`.

## Структура
- `Джаз вечер. /Лендинг версия C/` — исходники актуального лендинга.
- `Джаз вечер. /Лендинг версия C/app/page.tsx` — содержание, сцены и CTA.
- `Джаз вечер. /Лендинг версия C/app/globals.css` — визуальная система и адаптив.
- Корневые `index.html`, `_next/` и публичные ассеты — статический экспорт для GitHub Pages.
- `lb/` и `Джаз вечер. /Карта проекта.md` — исследования ЦА, оффера и смысловая архитектура.

## Ключевые решения
- Первый экран не менять без отдельной просьбы.
- Формат: беседа становится материалом для живой джазовой импровизации.
- После общей картины идут музыканты, затем тема первой встречи.
- Карточный вариант музыкантов отклонён; актуальна свободная сценическая композиция.
- Не выдумывать имена, регалии, отзывы, условия возврата и другие доказательства.
- GitHub Pages публикуется из корня ветки `main` с base path `/kontrapunkt`.

## Что сделано
- Проведён большой аудит desktop/mobile, контента, конверсии и техники.
- Добавлен безопасный base path для HTML-, CSS- и favicon-ассетов: локально `/`, на Pages `/kontrapunkt`.
- Актуальная версия C экспортирована через Next.js и проверена локально по пути `/kontrapunkt/`.
- Основная страница, JS/CSS и ключевые изображения отвечают `HTTP 200`.
- Lint и статическая production-сборка проходят; консоль чистая.
