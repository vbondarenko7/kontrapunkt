# salon-landing

## Статус

В ветке `version-d` готов закрытый прелонч со сбором контактов. Приватная
Sites-версия 3 опубликована только для владельца:
`https://kontrapunkt-salon.gvclikegods.chatgpt.site`.
`main` и публичная GitHub Pages-версия C не изменены.

## Структура

- `Джаз вечер. /Лендинг версия C/app/page.tsx` — девять секций и форма
  предварительного списка.
- `Джаз вечер. /Лендинг версия C/app/globals.css` — визуальная система,
  адаптив и состояния формы.
- `Джаз вечер. /Лендинг версия C/worker/index.ts` — API записи контактов и
  owner-only CSV-выгрузка `/api/waitlist`.
- `Джаз вечер. /Лендинг версия C/db/schema.ts`, `drizzle/` — D1-схема и
  миграция предварительного списка.
- `screenshots/version-d/` — контрольные кадры версии D.
- `DECISIONS.md` — долгие решения проекта.

## Ключевые решения

- Version D остаётся отдельной веткой до приёмки; публичная версия C не
  затронута.
- Прелонч собирает необязательное имя и email или Telegram; дубли контактов не
  создаются.
- Закрытый стенд owner-only. Доступ другим участникам и публичный запуск
  требуют отдельного решения.
- Неподтверждённые факты не придумываются; их заполняет Вадим.

## Что сделано

- CTA «Купить билет» заменены на вход в предварительный список.
- Добавлены состояния отправки, успеха и ошибки, согласие на одно сообщение и
  антиспам-поле.
- Контакты сохраняются в D1 без IP и user-agent; добавлена уникальность и
  тесты повторной отправки.
- Добавлена закрытая CSV-выгрузка для аккаунта владельца.
- Удалён неиспользуемый стартовый skeleton и его зависимость.
- Next обновлён с 16.2.6 до 16.2.12: прямые уязвимости текущего патча закрыты.
- Сборка, lint и шесть тестов проходят; приватная версия 3 опубликована,
  главная страница и API отвечают без ошибок.
