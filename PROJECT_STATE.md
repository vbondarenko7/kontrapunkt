# salon-landing

## Статус

В локальной версии D исправлена типографика: короткие русские предлоги и союзы
связаны со следующим словом неразрывными пробелами, вертикальные отступы основных
контентных секций унифицированы. Изменения не публиковались на GitHub Pages.

## Структура

- `Джаз вечер. /Лендинг версия C/app/page.tsx` — актуальная страница D и весь текст.
- `app/globals.css` внутри лендинга — стили и единый токен `--section-space`.
- `tests/rendered-html.test.mjs` — проверки серверного HTML и неразрывных пробелов.
- `docs/copy-approved-draft-2026-07-31.md` — источник согласованного текста.
- `../TYPOGRAPHY_RULES.md` — общий обязательный регламент для будущих сайтов.
- Корневые `index.html`, `_next/` и ассеты — текущий опубликованный экспорт.

## Ключевые решения

- Порядок девяти секций и полноэкранные hero/сценические блоки не менять.
- Внешний вертикальный ритм контентных секций: 112 px на широких экранах,
  76 px на мобильных; значения задаются через `--section-space`.
- Текст считается живой частью дизайна: типографику делать устойчивой с первого
  прототипа и повторно проверять после заметных контентных правок.
- H1 занимает три строки на 390 px.
- CTA не подключать без рабочей билетной ссылки; цену 2 300 ₽ подтвердить.
- Мраморного философа позже заменить живой сценой общения гостей.
- Публиковать GitHub Pages только по отдельному подтверждению Вадима.

## Что сделано

- Убраны висящие короткие предлоги/союзы во всём пользовательском тексте страницы.
- Одинаковый вертикальный отступ применён к why, format, theme, musicians,
  ticket, FAQ и финальной секции; режиссура полноэкранных сцен сохранена.
- В корне `Workflow` создан обязательный регламент `TYPOGRAPHY_RULES.md`, ссылка
  на него добавлена в `SHARED_PROTOCOL.md`.
- `npm run lint`, `npm test` и сборка проходят; 7 тестов зелёные.

3. Подтвердить цену, оферту, персональные данные, возрастную маркировку и
