# salon-landing

## Статус

Портрет ведущего опубликован на `https://jazzgovorit.ru/` и в закрытой Sites-версии.
Цена билета — `2 300 ₽`; обе кнопки ведут на Prodamus, подключённый к НПД.

## Структура

- `Джаз вечер. /Карта проекта.md` — главный документ проекта.
- `Джаз вечер. /Лендинг версия C/app/page.tsx` — лендинг и CTA покупки.
- `Джаз вечер. /Лендинг версия C/app/globals.css` — визуальная система и адаптивы.
- `Джаз вечер. /Лендинг версия C/public/host-vadim-portrait.webp` — портрет ведущего.
- `Джаз вечер. /Лендинг версия C/app/payment-success/page.tsx` — успешная оплата.
- `Джаз вечер. /Лендинг версия C/app/payment-failed/page.tsx` — незавершённая оплата.
- `Джаз вечер. /Лендинг версия C/app/analytics.ts` — цели Яндекс Метрики.
- `Джаз вечер. /Лендинг версия C/public/favicon.svg` и `favicon.svg` — актуальный знак сайта.
- Корневые HTML, TXT и `_next/` — статическая сборка GitHub Pages.

## Ключевые решения

- Основной домен — `jazzgovorit.ru`; экранный бренд — «Разговор × Джаз».
- Для первой версии используется существующий аккаунт Prodamus и короткая платёжная ссылка.
- Prodamus подключён к НПД для автоматических чеков и корректировок при возврате.
- Favicon — красная реплика со светлой джазовой нотой на почти чёрном фоне.
- Покупатель и гость — разные роли; ядро первой продажи — женщина 28–42, планировщик вечера.
- Портрет ведущего собран из двух личных референсов: лицо и очки сохранены, кепка и наушники
  убраны, свет и фон приведены к тёмной клубной палитре сайта.

## Что сделано

- Timeweb DNS, HTTPS и редирект `www` настроены.
- Билет стоимостью `2 300 ₽`, цель Метрики `ticket_click` и страницы результата оплаты готовы.
- Заглушка фото ведущего заменена оптимизированным WebP-портретом с содержательным alt-текстом.
- Кадрирование, рамка, тёплая тонировка и адаптивы блока ведущего настроены.
- Desktop 1440 px и mobile 390 px проверены в браузере; ошибок консоли и загрузки ассета нет.
- Lint, 8 тестов, vinext build и Next.js static export проходят.
- Закрытая Sites-версия 8 и публичная GitHub Pages-версия опубликованы.
