## Ключевые решения
- Первый экран не менять без отдельной просьбы.
- После общей картины идёт блок музыкантов, затем тема первой встречи.
- Карточный вариант блока музыкантов отклонён и полностью удалён.
- Новый блок строится как свободная сценическая композиция: пианист и контрабасист, крупные слова «Слышат / Отвечают», естественные пропорции изображений.
- Блок объясняет роль исполнителей: они слушают беседу и отвечают импровизацией.
- Имена пока обозначены одной спокойной заглушкой; не выдумывать регалии и цифры.
- Маркер темы: «Тема первой встречи — № 01».
- Глаза статуи оставлены исходными; не добавлять моргание.
- GitHub Pages обновлять только по отдельной просьбе.

## Что сделано
- Полностью заменён шаблонный трёхколоночный блок музыкантов.
- Убраны растянутая фотография, панели и повторяющиеся карточки.

- При появлении блока фигуры сходятся навстречу, слова и подписи входят последовательно; анимация однократная.
- Сделана отдельная мобильная композиция и режим reduced motion.
- `npm run build`, ESLint и `git diff --check` проходят.
- Локальная страница и оба изображения возвращают `HTTP 200`.
