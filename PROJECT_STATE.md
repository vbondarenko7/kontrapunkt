# salon-landing

## Статус

Версия D с лаковой кнопкой и деревянной карточкой билета опубликована на
основном публичном адресе:
`https://vbondarenko7.github.io/kontrapunkt/`.
GitHub Pages собирается из корня `main`; `version-d` и `main` указывают на
актуальный релиз. Sites-версия 7 остаётся технической инфраструктурой и не
предлагается пользователю как способ просмотра.

## Структура

- `Джаз вечер. /Лендинг версия C/app/page.tsx` — девять секций version-d и
  форма предварительного списка для серверного стенда.
- `Джаз вечер. /Лендинг версия C/app/globals.css` — визуальная система и
  адаптив.
- `Джаз вечер. /Лендинг версия C/worker/index.ts` — D1 API контактов,
  owner-only CSV и CORS для GitHub Pages.
- `Джаз вечер. /Лендинг версия C/db/`, `drizzle/` — схема контактов и миграция.
- `screenshots/version-d-mobile/` — полный мобильный прогон и кадры секций
  390×844.
- `screenshots/version-d-button/` — контрольные кадры кнопок, билета и финала
  на 1440×900 и 390×844.
- Корневые `index.html`, `_next/`, `_not-found/` и ассеты — статический экспорт
  version-d для GitHub Pages.
- `DECISIONS.md` — долгие решения проекта.

## Ключевые решения

- Все мобильные правки находятся внутри `max-width`; десктоп от 981 px не
  менялся.
- На телефоне в ансамбле остаётся одна полностью видимая фигура контрабасиста;
  пианист и фоновые слова скрыты, подпись стоит обычным блоком ниже.
- Слот фотографии ведущего на телефоне — 224×280 px над текстом и готов к
  `object-fit: cover`.
- Кнопки остаются красным функциональным акцентом; от контрабаса взята только
  лаковая отделка. Деревянная фактура используется на карточке билета.
- GitHub Pages — статический хостинг. Публичный Sites/API запрещён настройками
  workspace, поэтому на Pages CTA показывает анонс без отправки контакта.
- Рабочая форма и CSV пока доступны только на приватном Sites-стенде.
- Неподтверждённые факты не выдумываются и остаются плейсхолдерами.

## Что сделано

- Пересобран мобильный ансамбль без горизонтальных вылетов.
- Ограничен слот ведущего, подняты мобильные кегли служебного текста и усилено
  затемнение сцены «Здесь слушают».
- Добавлены сбалансированные переносы заголовков; на 390 px все `h2` занимают
  не больше трёх строк.
- Плёночное зерно ограничено шириной контейнера.
- При временно отключённом `body { overflow-x: hidden; }` горизонтальной
  прокрутки нет; выходящих за правый край элементов не найдено.
- Секция музыкантов уменьшена с 2255 до 1998 px.
- `npm run lint`, `npm run build` и статический Next.js export проходят.
- Десктопные изменения отсутствуют в CSS: весь diff ограничен
  `@media (max-width: 980px/700px/480px)`.
- Статический экспорт и GitHub Pages обновлены до версии с лаковой кнопкой и
  деревянной карточкой билета.
- Основные CTA получили мягкий красный градиент, внутренние светлую и тёмную
  грани, тёплую тень и короткое состояние нажатия.
- Финальный CTA увеличен до 68 px; на телефоне занимает ширину колонки.
- Карточка билета получила тёмное красное дерево, едва заметную продольную
  фактуру, верхнее лаковое свечение и более глубокую тень.
- Контраст списка на самом светлом участке карточки — 8.14:1 против прежних
  8.07:1.
- `npm run lint` и `npm run build` проходят; набор файлов `public/` не менялся.
