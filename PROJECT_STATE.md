## Ключевые решения

- Порядок девяти секций не меняется.
- Точный H1 занимает три строки на 390 px.
- CTA не подключать без рабочей билетной ссылки.
- Цену 2 300 ₽ подтвердить перед публикацией.
- Мраморного философа позже заменить живой сценой общения гостей.
- GitHub Pages не обновлять без отдельного подтверждения Вадима.
