# Задание для Codex: мобильная вёрстка версии D

## Контекст

Версия D по десктопу закончена и принята. Теперь доводим телефон — до сих пор им
никто не занимался специально, и там накопились огрехи.

Работаем в той же ветке `version-d`. Файлы те же:
`Джаз вечер. /Лендинг версия C/app/page.tsx` и `app/globals.css`.

Все цифры ниже сняты вживую на 390×844 (iPhone, DPR 2) с локального дев-сервера,
не на глаз. Если что-то перепроверяешь — снимай так же.

## Что уже сделано Claude Code, не переделывай

За последние два захода в проекте уже изменено следующее. Это готово и проверено,
трогать не нужно:

   почти касаются (в просвете две красные засечки) и расходятся. При появлении секции

   цитата и вопрос. Классы `.theme-paths`, `.theme-path`, `.theme-tick`.
   Цитата расширена до 620px и уменьшена до 33px, чтобы строки Гумилёва не рвались.
   Финальный вопрос увеличен до 28px и поднят.
2. **Вес страницы.** Четыре PNG-вырезки переведены в WebP: 3797 КБ → 368 КБ.
   Старые PNG удалены, ссылки в `page.tsx` обновлены. Картинки на странице: 4,23 МБ → 0,88 МБ.
3. **Шрифты.** Запрос к Google Fonts вынесен из `@import` в `globals.css` в `<link>`

4. **Заголовок первого экрана.** В текстовых узлах не хватало двух пробелов
   («душам,который», «становитсяживым»). Проставлены через `{" "}`. Не схлопывай обратно.
5. **Неиспользуемые картинки.** Девять файлов, которые страница не запрашивает, вынесены
   из `public/` в `Джаз вечер. /Неиспользуемые картинки/`. `public` похудела с 6,3 МБ до 1,3 МБ.
   Обратно не возвращай.

## Правила

1. **Меняем только поведение на узких экранах.** Десктоп от 981px должен остаться
   пиксель в пиксель таким же. Все правки — внутри медиазапросов `max-width`.
2. Никаких новых картинок, шрифтов и библиотек.
3. Тексты не трогаем вообще — ни одной формулировки.
4. Заглушки `[ЗАПОЛНИТЬ: …]` остаются на месте.
5. Коммить отдельными коммитами по задачам.

## Задача 1. Ансамбль музыкантов — единственная настоящая поломка

Сейчас на 390px:

- `.ensemble-bassist` уезжает на **94px за правый край экрана**;
- фоновые слова «СЛЫШАТ» и «Отвечают» тоже уходят за край и обрезаются на полубукве;
- контрабасист наезжает на пианиста, пианист виден наполовину.

Видно это только потому, что у `body` стоит `overflow-x: hidden` — он прячет
горизонтальную прокрутку, но не чинит вылет, содержимое просто отрезается.

**Что сделать.** На экранах до 700px собрать блок заново, а не подпирать текущий.
Рекомендация: оставить **одну** вырезку — контрабасиста — вписанной в ширину экрана
целиком, пианиста и фоновые слова скрыть. Одна крупная фигура делает работу блока
(«на сцене профессиональные музыканты») лучше, чем две обрезанные и налезающие
друг на друга. Подпись `.ensemble-note` оставить под фигурой обычным блоком.

Если найдёшь решение с двумя фигурами, которое влезает без обрезки, — тоже годится,
критерий один: ничего не выходит за правый край.

## Задача 2. Заглушка фото ведущего

Сейчас это пустой прямоугольник **350×438px** — почти пол-экрана пустоты.

На экранах до 700px:

- поставить блок портрета **над** текстом;
- ограничить высоту примерно 280px, ширину — по контенту, не на всю колонку;
- когда появится настоящая фотография, она должна лечь в тот же слот через
  `object-fit: cover`, чтобы правка не пропала.

## Задача 3. Мелкий текст

Замеренные размеры на телефоне и во что их привести:

| элемент | сейчас | нужно |
|---|---:|---:|
| `.layered-scenario p` | 12px | 15px |
| `.layered-lead` | 14px | 16px |
| `.limited` | 12px | 14px |
| `.host-signature` | 11px | 13px |

Надстрочники `.eyebrow` и `.chapter` по 11px — это капслочные метки, их не трогаем.

Отдельно: текст блока «Здесь не оценивают» лежит поверх фотографии клуба и на телефоне
читается тяжело. Усилить затемняющую подложку под текстовой колонкой на узких экранах,
чтобы контраст был уверенным, а не пограничным.

## Задача 4. Заголовки рвутся по строкам

На 390px:

- «Такие / разговоры / **не** / случаются / сами» — предлог висит один на строке;
- «Созданные / друг для друга / проходят / **мимо**» — последнее слово одно на строке.

Что сделать:

- добавить `text-wrap: balance` для `h1, h2, h3` — браузер сам разложит строки ровнее;
- дополнительно уменьшить кегль `h2` на экранах до 480px настолько, чтобы заголовки
  укладывались в три строки, а не в пять.

## Задача 5. Плёночное зерно шире экрана

`.film-grain` и `.film-grain.layered-grain` имеют ширину **638px** при экране 390px —
перелёт 248px. Само по себе не видно, это текстура, но чинится одной строкой:
привести ширину к 100% контейнера.

## Задача 6. Проверка на вылет

`overflow-x: hidden` у `body` маскирует ошибки вёрстки. Не полагайся на него.

Проверка: временно отключи `overflow-x: hidden`, прогони страницу на 390px и убедись,
что горизонтальной прокрутки нет и ни один элемент не выходит за правый край.
После проверки правило верни на место.

## Как проверить, что сделано

Замеры снимать на 390×844, DPR 2, прогнав страницу до конца, чтобы отработали анимации.

1. `npm run lint` и `npm run build` проходят без ошибок и предупреждений.
2. Ни один элемент внутри `main` не выходит за правый край экрана.
3. Основной текст на телефоне — не мельче 15px.
4. Ни один заголовок не заканчивается одиноким предлогом или коротким словом на строке.
5. Секция музыкантов на телефоне стала ниже (сейчас 2255px, то есть 2,7 экрана).
6. Десктоп на 1440×900 не изменился — сравни скриншоты с `screenshots/version-d/`.
7. Скриншоты мобильной версии положить в `screenshots/version-d-mobile/`.
